# HakiSend Publisher for Obsidian

Draft, publish, and schedule website posts and prepare email campaigns from your Obsidian vault through your HakiSend account.

**Status:** Version 0.1.41 is the first public-release candidate intended for Obsidian Community review. It is not an officially approved Community plugin until Obsidian accepts the listing. Desktop publishing and one-recipient email delivery were verified on the preceding 0.1.40 client; the 0.1.41 client includes additional security hardening. Mobile behavior has not been verified.

## Requirements and external services

- Obsidian 1.11.4 or later.
- A HakiSend account and access to a HakiSend Site.
- Internet access to the HakiSend HTTPS API (default `https://app.hakisend.com`).
- Some publishing and email features require a paid HakiSend plan.

The plugin sends the Markdown content, attachments, and metadata necessary for the actions you explicitly request to HakiSend's servers. It connects using browser-based OAuth; access credentials are stored in Obsidian Secret Storage. It does **not** run client-side analytics or advertisements.

HakiSend processes the content and request metadata needed to carry out publishing and email operations. Service-side operational logs may be generated by HakiSend; these are distinct from analytics or telemetry embedded in this plugin. Consult HakiSend's official service terms and privacy disclosures before connecting your account.

## Source code and release verification

The source repository is **private**. The official Obsidian Community directory GitHub App will receive read-only access to that source for build verification. This public repository contains distribution metadata and release artifacts, not the private development history. The built JavaScript distributed in GitHub Releases is inspectable by users. Closed-source distribution is disclosed here for Community policy review.

The public repository root contains this `README.md`, `LICENSE`, `manifest.json`, and `versions.json`. GitHub Release `0.1.41` must provide the standalone asset files `main.js`, `manifest.json`, and `styles.css`.
